## Experiência na prática

- Desenvolvi a Sol, assistente de consulta de dados pelo WhatsApp, usando a API oficial da Meta. Cada loja só acessa seus próprios dados, com validação de permissões e verificação das respostas.
- Automatizei a cobrança de boletos integrando ERP e WhatsApp com Python, FastAPI e Next.js. A automação liberou uma pessoa de uma rotina manual que ocupava o dia inteiro.
- Mantenho pipelines no Microsoft Fabric para uma plataforma com mais de 3,8 bilhões de registros e mais de 800 lojas em 23 estados. As validações bloqueiam dados incompletos e permitem reprocessar períodos sem duplicação.
- Criei um painel com FastAPI, Next.js e KQL no Azure Log Analytics para investigar falhas da IA e acompanhar o custo e a qualidade das respostas.

### [EvidenceDesk](https://github.com/arthurjoanes/evidencedesk)

Investiga divergências entre pedidos e pagamentos, com acesso às fontes e revisão por outra pessoa antes da aprovação. A IA é opcional e serve para preparar rascunhos.

**Python · FastAPI · PostgreSQL · Next.js · Azure OpenAI opcional**

### [Gestão de Recebíveis](https://github.com/arthurjoanes/gestao-recebiveis)

Controle de contas a receber com importação CSV, registro de pagamentos e retomada de tarefas interrompidas. Evita pagamentos duplicados e separa tentativas de envio de lembretes das entregas confirmadas. O provedor de mensagens é simulado.

**Python · FastAPI · PostgreSQL · Next.js · Docker**

### [Varejo Data Pipeline](https://github.com/arthurjoanes/varejo-data-pipeline)

Processa vendas, verifica a cobertura dos dados e publica indicadores. Se um lote falha ou é bloqueado, os indicadores anteriores continuam disponíveis. Inclui cenários locais para testar revisões e retomadas.

**Python · PySpark · Delta Lake · SQL · Docker**
